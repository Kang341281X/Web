# Prompt
1、价格区间部分的样式要修改，删除下面的一行小字：商品标价为人民币，输入金额将按当前语言汇率换算筛选。
2、价格区间部分的最高价和最低价的实现逻辑要正确，用户输入最低价时，最高价自动变为最低价，并且最高价不能低于最低价；用户输入最高价时，最低价自动变为最高价，并且最低价不能高于最高价。

注意：所有改变都要适配移动端设备，包括但不限于苹果、安卓等。
